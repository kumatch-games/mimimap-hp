## Publishing and maintenance

GitHub Pages publishes the root directory of the `main` branch. Static HTML/CSS with no build dependencies, JavaScript, analytics, or external fonts. Each page links to its translated equivalent. Keep English and Japanese aligned when editing. `.nojekyll` disables Jekyll processing.

The privacy policy reflects the current app as of 2026-10-11: Overpass API at `overpass-api.de`, Apple MapKit, local app storage, WatchConnectivity, and the contact form above. Review it before changing map services, analytics, purchases, storage, or contact handling. Third-party log retention is controlled by those providers. The App Store privacy questionnaire is a separate review.
